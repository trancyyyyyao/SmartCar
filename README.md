# m0-m6-practice

22 智能车创意组一轮考核的练习仓库，按「模块 / 题目」两级组织。

题目材料来自：https://github.com/Blake-John/22SmartCar

## 目录结构

| 路径 | 内容 | 状态 |
| :-- | :-- | :-- |
| `M0/M0-1/` | 从零搭建开发环境 | 待开始 |
| `M0/M0-2/` | 首个代码工具（重构相关系数脚本） | 进行中 |
| `M0/M0-3/` | 代码排查 | 待开始 |
| `M0/M0-4/` | Mini 项目实战 | 待开始 |

> 做到哪一题就建哪一题。Git 不记录空目录，空的文件夹推不上去。

## 怎么运行

每个题目目录下都有独立的 `README.md`，写明该题的运行方式、输入格式与输出含义。

## 说明

- 各题目目录下的 `legacy/` 存放考核方提供的原始材料，仅作对照，不参与运行。
- 数据集、视频、模型权重等大文件不入库，改在对应题目的 `README.md` 里附网盘链接与校验码。
