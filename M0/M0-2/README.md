## 如何运行

```bash

pip install -r requirements.txt

python3 corr_tool.py --config config.yaml
```

> 入口脚本名可自定；改了之后记得同步更新本节和根目录的说明。

## 输入文件格式

### 配置文件（yaml）

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `input_csv` | str | 数据文件路径。**相对路径以配置文件所在目录为基准**解析，与当前工作目录无关 |
| `columns.x` | str | 参与计算的第一列列名 |
| `columns.y` | str | 参与计算的第二列列名 |
| `task.verbose` | bool | 示例配置中的可选项；当前实现固定打印 n / mean_x / mean_y，不读取该字段 |

### 数据文件（csv）

- 必须有表头
- 至少包含 `columns.x` 与 `columns.y` 指定的两列
- 两列取值必须能转成浮点数
- 文件按 **UTF-8** 读取
- **空值或非数值会让程序报错退出**（退出码 1），不会跳过该行，也不会用 0 填充

## 输出结果的含义

结果打印到 stdout，其中必须包含一行 `r = <数值>`。

| 输出 | 含义 |
| :-- | :-- |
| `n` | 参与计算的有效样本数 |
| `mean_x` / `mean_y` | 两列的算术平均值 |
| `r` | 皮尔逊相关系数，取值范围 -1 ~ 1 |

**r 的解读：**

| r 的取值 | 含义 |
| :-- | :-- |
| `r > 0` | 正相关：x 增大时 y 也倾向增大 |
| `r < 0` | 负相关：x 增大时 y 倾向减小 |
| `r ≈ 0` | 线性关系很弱或没有 |
| `r = 1` | 完全正线性相关 |
| `r = -1` | 完全负线性相关 |

绝对值越接近 1，线性关系越强；越接近 0 越弱。
注意 r 只衡量**线性**关系——x 与 y 有很强的非线性关系时，r 也可能接近 0。

**异常情况下的表现：**

所有错误信息输出到 **stderr**，并**不抛出 Traceback**：

| 情况 | 提示 | 退出码 |
| :-- | :-- | :--: |
| 配置文件不存在 / csv 不存在 | `错误：找不到文件「...」` | 1 |
| yaml 语法错误 | `错误：...` | 1 |
| 缺少字段（如缺 `columns`） | `错误：缺少必要的字段或列名 'columns'` | 1 |
| csv 缺少指定列 | `错误：缺少必要的字段或列名 '列名'` | 1 |
| 配置文件为空 | `错误：配置文件是空的` | 1 |
| csv 没有数据行 | `错误：没有读到任何数据` | 1 |
| 某一列数值恒定（方差为 0） | `错误：某一列的数值完全一样（方差为 0）...` | 1 |
| 正常 | `n = ... mean_x = ... mean_y = ... r = ...` | 0 |
